JavaScriptで単位の換算を行うページです。

 

換算式や項目の選択は、Wikipediaより行いました。単位の日本語読みはWikipediaの該当ページへのリンクとなっています。一般的な換算式の一覧は『単位の換算一覧（Wikipedia）』にまとめられていますので大変役立つと思います。

利用しているJavaScriptは、Jonathan Weesner氏のGeneric Unit Conversion Program（1995年11月25日版）を改造したものです。（初版の著作権が放棄されていますので、私も米国法に従い改変部分の著作権を放棄します。）
